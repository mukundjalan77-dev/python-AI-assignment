## 💻 Program Descriptions

### 1. `factorial.py`

**Purpose:** Calculates the factorial of a number.

The factorial of a non-negative integer \(n\) is the product of all positive integers from 1 to \(n\). The factorial of 0 is defined as 1.

**Example:**

Input:
```text
Enter a number: 5
```

Sample output:
```text
Factorial of 5 is 120
```

**Concepts covered:**
- Variables and input
- Loops
- Multiplication
- Conditional logic, if used in the implementation

### 2. `fibonacci.py`

**Purpose:** Prints a Fibonacci series.

The Fibonacci series is a sequence in which each number, after the first two, is the sum of the preceding two numbers.

**Example:**

Input:
```text
Enter the number of terms: 7
```

Sample output:
```text
Fibonacci series:
0 1 1 2 3 5 8
```

**Concepts covered:**
- Variables
- Loops
- Sequence generation
- Basic arithmetic operations

### 3. `student_dictionary.py`

**Purpose:** Represents student information, similar to the data stored in a C structure, using a Python dictionary.

In C, a structure groups related variables under one type. In Python, a dictionary stores data as key-value pairs.

**Illustrative example:**

```python
student = {
    "name": "Rahul",
    "roll_no": 101,
    "marks": 85.5
}

print(student)
```

Sample output:
```text
{'name': 'Rahul', 'roll_no': 101, 'marks': 85.5}
```

**Concepts covered:**
- Dictionaries
- Key-value pairs
- Data representation
- Accessing and storing related information

*Note: The example above illustrates the concept. The actual output of your file depends on its implemented values and print statements.*

## 🔍 Key Differences Between C and Python

| Feature | C | Python |
|---|---|---|
| Syntax | Uses braces and semicolons in common constructs | Uses indentation to define code blocks |
| Typing | Statically typed | Dynamically typed |
| Compilation | Commonly compiled before execution | Commonly executed by a Python interpreter |
| Variables | Types are explicitly declared | Types are determined at runtime |
| Data structures | Structures and arrays are commonly used | Lists, dictionaries, tuples, and other built-in types are available |
| Memory management | Provides manual memory-management facilities | Uses automatic memory management |
| Code length | Often requires more setup code | Often requires less code for similar tasks |
| Input/output | Uses functions such as `scanf()` and `printf()` | Uses functions such as `input()` and `print()` |

**Summary:** C provides more direct control over memory and low-level operations, while Python emphasizes readability and ease of development. Both languages are useful for learning programming fundamentals.
